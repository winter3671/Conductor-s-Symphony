# 🎼 Conductor's Symphony (컨덕터스 심포니)
> **"몰려오는 음표 군단에 맞서 5개의 악기를 조율하라!"**
> 2D 도트 픽셀 아트 기반의 하드코어 리듬 × 뱀파이어 서바이버즈 탑뷰 생존 웹 게임

---

## 1. 프로젝트 개요 (Overview)

* **프로젝트명:** Conductor's Symphony (가제: 리듬뱀서)
* **플랫폼:** Web (Unity WebGL, PC 브라우저 최적화 / GitHub Pages 자동 배포 파이프라인 구축)
* **장르:** 하드코어 리듬 액션 × 로그라이트 서바이벌 (Rhythm × Roguelite Survivor)
* **조작계:** 
  * **왼손 (`Q, W, E, R, Space`):** 5방향 리듬 노트 입력 (연주)
  * **오른손 (`방향키`):** 캐릭터 이동 및 탄막 회피 (무빙)
* **핵심 컨셉:** 연주복을 입은 '지휘자'가 악기들을 하나씩 조율하고 수집(인크레디박스 스타일)하면서, 맵 사방에서 몰려오는 음표 몬스터들을 오토 타겟팅 연주로 쓸어버리는 탑뷰 생존 게임.

---

## 2. 아트 및 비주얼 디자인 (Visual Design)

* **화풍 (Art Style):** 레트로 감성의 **2D 도트(Pixel Art) 그래픽**
  * 후반부 피사체 팽창 시 피아식별이 불가능해지는 시각적 피로도와 난잡함을 방지하고 고전 게임 특유의 직관성을 확보.
* **캐릭터 & 무기 연출:** 
  * **지휘자 (Player):** 턱시도와 연주복을 입은 클래식한 지휘자 형태.
  * **악기 위성 (Weapons):** 획득한 무기(악기, 최대 5개)는 지휘자 주변을 오비탈처럼 둥둥 떠다니거나 브레멘 음악대처럼 캐릭터 뒤를 졸졸 따라다니며 스스로 연주되는 위트 있는 연출.
* **음표 군단 (Enemies):** 
  * 8분음표, 높은음자리표, 쉼표, 16분음표 등 다양한 음악 기호를 형상화한 도트 캐릭터로 제작하여 직관적인 음악 테마 전달.

---

## 3. 핵심 시스템: 5방향 콤팩트 원형 레코드판 UI

* **컴팩트 판정선 UI:** 캐릭터 발밑 및 몸집에 바짝 붙은 작은 **5등분 원형 레코드판 링 UI** 배치.
  * 화면 중앙을 가리지 않고 360도 전방의 적과 탄막 시야를 완벽하게 확보.
  * 적/투사체 영역과 리듬 노드 영역을 시각적으로 완전히 격리하여 피로도 극소화.
* **5방향 노드 라인:** 하단, 좌측, 좌상단, 우상단, 우측 총 5방향의 외곽 링에서 중앙의 캐릭터(판정선)를 향해 축소되며 다가오는 노드를 왼손으로 박자에 맞춰 타격.
* **사운드 Ducking 제어:** 적 타격음 및 죽는 소리는 무음 또는 최소화하고, 유저가 입력한 **선명한 악기 연주음과 캐릭터 피격음만 상단 믹싱**하여 청각적 혼란 방지.

## 4. 전투 메커니즘 & 무기 슬롯 해금 (Incredibox 벤치마킹)

### 4.1. 하이브리드 발사 방식
* **평시 오토 기본 공격:** 리듬을 치지 않아도 최소한의 약한 기본 공격이 오토 타겟팅으로 상시 발사되어 극초반 잔챙이 잡몹 소탕 가능.
* **비트 성공 시 (Perfect/Great):** 기본 대미지의 300~500% 폭발적 대미지, 투사체 거대화, 광역 충격파 발동.
* **Miss 패널티:** 노트 타이밍 실패 시 강화 공격 발동 실패, 콤보 리셋, 순간적 발사 쿨타임 증가로 패배 원인을 유저 피지컬로 명확히 인과관계 제시.

### 4.2. 단계적 무기 슬롯 해금 & 노트 확장
유저가 선택하는 무기(악기)에 따라 BGM에 사운드 트랙이 실시간 레이어링되며 채보가 확장되는 구조.

| 슬롯 단계 | 해금 조작 키 | 악기 & 사운드 트랙 | 리듬 채보 및 유저 경험 |
| :--- | :--- | :--- | :--- |
| **1슬롯 (극초반)** | `Q` 단일 키 | 기초 비트 (드럼/타악기) | 정직한 정박 연주로 기본 이동 및 무빙 파밍 적응 |
| **2슬롯** | `Q`, `W` | + 베이스 / 리듬 세션 추가 | BGM이 풍성해지며 2개 키 조합 채보 등장 |
| **3~4슬롯** | `Q`, `W`, `E`, `R` | + 신디사이저 / 바이올린 | 4개 키를 사용하는 다채로운 멜로디 채보 구성 |
| **5슬롯 (최대)** | `Q`, `W`, `E`, `R`, `Space` | + 풀 오케스트라 / 세션 | 나만의 완성된 곡 완성 + 5키 풀 채보 연주 |

## 5. 레벨 디자인 & 보스전 (협주곡 클라이맥스)

* **일반 웨이브 (잡몹전):**
  * 오른손(방향키) 무빙 부담이 적은 상태에서 정박 위주의 리듬 연주(왼손)에 집중.
  * 사방에서 몰려오는 음표 몬스터들을 시원하게 쓸어버리는 뱀서 특유의 성장의 쾌감 제공.
* **보스전 (협주곡 클라이맥스 - 난이도 폭발):**
  * **컨트롤의 무게중심 이동:** 보스 진입 시 여러 악기가 어우러지는 웅장한 협주곡 BGM으로 전환.
  * **리듬 쉴드 (Rhythm Shield):** 보스는 일반 오토 공격으로 딜이 들어가지 않으며, 정확한 비트 타격을 통해서만 깨지는 특수 방어막 보유.
  * **조작 피로도 제어:** 왼손의 리듬 노트 패턴(속도/방향)은 일반 웨이브와 동일하게 유지하여 익숙해진 박자 템포를 지킴.
  * **오른손 무빙의 극대화:** 리듬 템포는 유지하되 보스의 거대한 탄막과 광역 장판 기믹이 쏟아져 **오른손(이동) 회피 컨트롤 난이도가 극상승**.
  * 단순한 버튼 연타(메트로놈화)를 방지하고, 무의식적인 왼손 연주와 정교한 오른손 무빙이 결합된 하드코어 '복합 피지컬' 요구.

## 6. 기술 스택 및 개발 파이프라인 (Tech Stack)

* **Engine & Language:** Unity (2D), C#
* **Audio System:** Unity AudioEngine (`AudioSettings.dspTime` / `AudioSource` 기반 정밀 박자 및 Stem Audio 동기화 Engine)
* **DevOps:** Git, GitHub, GitHub Actions (Unity WebGL 자동 빌드 및 GitHub Pages 배포 파이프라인 구축)
* **AI-Assisted Production (개발 파이프라인):**
  * **Graphics:** Generative AI (Midjourney / Stable Diffusion) 프롬프트 연동을 통한 2D 도트 픽셀 아트 소스 및 UI 초속 확보
  * **Audio:** 오디오 생성 AI (Suno / Udio)를 활용해 무기별 분리 트랙(Stem Audio) 및 장르별 BGM 생성
  * **Game Balance:** LLM 프롬프팅을 통한 수치 인플레이션 시뮬레이션 및 경험치 곡선 최적화
