리듬 게임 1\~16마디 악기별 정밀 노트 설계서
===========================================

본 문서는 1마디를 16분 음표 기준 16개 칸(그리드 1\~16)으로 분할하여,
10개 악기 전체의 **1\~16마디 정확한 노트 입력 위치, 노트
종류(단타/롱노트/연타/숏홀드), 입력 길이를 정의**한 완성형 개발
가이드입니다.

*※ 롱노트 악기(바이올린, 플루트, 프렌치 호른, 첼로, 팀파니)는 플레이어의
손가락 피로도를 줄이고 명확한 박자감을 전달하기 위해 모든 홀드 직후
2\~4칸의 여유 휴식 간격(Release Window)을 포함하고 있습니다.*

📌 그리드 칸 위치 및 박자 기준표 (1마디 = 16칸)
----------------------------------------------

  -------------------- -------------------- -------------------- -------------------- ---------------------
  **박자 위치**        **1박자 (Beat 1)**   **2박자 (Beat 2)**   **3박자 (Beat 3)**   **4박자 (Beat 4)**
  **그리드 칸 번호**   1, 2, 3, 4번 칸      5, 6, 7, 8번 칸      9, 10, 11, 12번 칸   13, 14, 15, 16번 칸
  **정박 위치**        1번 칸               5번 칸               9번 칸               13번 칸
  **엇박자 위치**      3번 칸               7번 칸               11번 칸              15번 칸
  -------------------- -------------------- -------------------- -------------------- ---------------------

🥁 1. 드럼 (Drum Machine) --- \[정박 비트 키퍼\]
-----------------------------------------------

-   **조작 컨셉:** 1, 3박자(Kick)와 2, 4박자(Snare)를 일정하게 눌러
    리듬의 뼈대를 지키는 안정감 (Tap Only)

  --------------- ------------------------------- -------------------------------- ------------------------------------------
  **마디**        **입력 칸 번호**                **노트 종류 및 길이**            **손맛 & 조작 특징**
  **1\~15마디**   **1, 5, 9, 13번**               **정박 비트 단타 (1칸)** x 4회   Kick(1, 9) + Snare(5, 13) 표준 정박 타격
  **16마디**      1, 5, 9, 11, 13, 14, 15, 16번   **필인(Fill-in) 연속 단타**      드럼 세트 필인 피날레 연타
  --------------- ------------------------------- -------------------------------- ------------------------------------------

🎹 2. 피아노 (Piano) --- \[리드미컬 단타 & 당김음\]
--------------------------------------------------

-   **조작 컨셉:** 롱노트 0%, 오직 손가락 끝으로 튕겨내는 리드미컬 단타
    (Tap Only)

  ------------ ------------------------- -------------------------------- ----------------------------------
  **마디**     **입력 칸 번호**          **노트 종류 및 길이**            **손맛 & 조작 특징**
  **1마디**    1, 5, 9번                 단타 (1칸) x 3회                 정박 1, 2, 3박자 타격
  **2마디**    3, 7번                    엇박 단타 (1칸) x 2회            1, 2박자 앤드(Off-beat) 튕기기
  **3마디**    5, 9번                    단타 (1칸) x 2회                 중저음 반주 엑센트
  **4마디**    1, 5, 9, 13번             정박 단타 (1칸) x 4회            4박자 리드미컬 연타
  **5마디**    3, 7, 11번                엇박 단타 (1칸) x 3회            신나는 당김음(Syncopation) 리듬
  **6마디**    1, 5, 7, 11번             복합 단타 (1칸) x 4회            정박과 엇박이 섞이는 리듬감
  **7마디**    1, 5, 9, 13번             정박 단타 (1칸) x 4회            정돈된 4박자 타격
  **8마디**    3, 7, 11, 15번            엇박 단타 (1칸) x 4회            전반부 마무리의 경쾌함
  **9마디**    1, 5, 9번                 단타 (1칸) x 3회                 후반부 하이라이트 진입
  **10마디**   3, 7, 11번                엇박 단타 (1칸) x 3회            화려한 건반 튕김
  **11마디**   1, 5, 9번                 단타 (1칸) x 3회                 정박 리듬 유지
  **12마디**   3, 7, 13번                복합 단타 (1칸) x 3회            마디 끝 포인트 타격
  **13마디**   1, 5, 9, 13번             정박 단타 (1칸) x 4회            빌드업 4박자 타격
  **14마디**   **1, 3, 5, 7, 9, 11번**   **연속 쾌속 단타 (1칸) x 6회**   건반 화음 쏟아지는 타격감 버스트
  **15마디**   1, 5, 9, 13번             정박 단타 (1칸) x 4회            클라이맥스 박자 조이기
  **16마디**   1, 5, 9번                 단타 (1칸) x 3회                 루프 전 깔끔한 마무리

🎻 3. 바이올린 (Violin) --- \[메인 멜로디 / 롱노트 + 릴리즈\]
------------------------------------------------------------

-   **조작 컨셉:** 롱노트 끝에 **3칸 손 떼기 간격**을 제공하여
    활질(Stroking) 박자감과 릴리즈 참격 손맛 형성

  ------------ ------------------------- -------------------------------- -------------------------------------------------------------------------------------------------------------------------------------
  **마디**     **입력 칸 번호**          **노트 종류 및 길이**            **손맛 & 조작 특징**
  **1마디**    **1\~13번**               **롱노트 (13칸)**                \[14\~16번 3칸 휴식\] A5 메인 멜로디 이끌기
  **2마디**    **5\~11번**, 13번         **중형 롱노트 (7칸)** + 단타     \[12번 1칸 / 14\~16번 3칸 휴식\] C5, B4 연결
  **3마디**    **1\~6번**, **9\~14번**   **중형 롱노트 (6칸)** x 2회      \[7\~8번, 15\~16번 각 2칸 휴식\] G5 → E5 활 바꾸기
  **4마디**    **1\~13번**               **롱노트 (13칸)**                \[14\~16번 3칸 휴식\] D5 음 유도하기
  **5마디**    5, 9, 13번                단타 (1칸) x 3회                 C5, D5, A5 짧은 멜로디
  **6마디**    1, 5, 9번                 단타 (1칸) x 3회                 E5, F5, E5 멜로디
  **7마디**    **1\~6번**, **9\~14번**   **중형 롱노트 (6칸)** x 2회      \[7\~8번, 15\~16번 각 2칸 휴식\] G5, D5 롱노트
  **8마디**    **1\~13번**               **롱노트 (13칸)**                \[14\~16번 3칸 휴식\] 전반부 멜로디 완성
  **9마디**    5번, **9\~14번**          단타 + **중형 롱노트 (6칸)**     \[15\~16번 2칸 휴식\] 후반 고음역 진입
  **10마디**   3, 7번, **11\~14번**      단타 2회 + **롱노트 (4칸)**      \[15\~16번 2칸 휴식\] B5, C6 활발한 멜로디
  **11마디**   1번, **5\~11번**          단타 + **중형 롱노트 (7칸)**     \[12\~16번 5칸 휴식\] G5 → C6 멜로디 치솟음
  **12마디**   **1\~13번**               **롱노트 (13칸)**                \[14\~16번 3칸 휴식\] 메인 멜로디 여운
  **13마디**   1, 5, 9번                 단타 (1칸) x 3회                 E5, A5, C6 하이라이트 준비
  **14마디**   1, 5, 9, 13번             **절정 연속 단타 (1칸)** x 4회   E6 고음역대 최고조 손맛
  **15마디**   1, 5, 9번                 단타 (1칸) x 3회                 A5, G5 멜로디 정돈
  **16마디**   **1\~13번**               **롱노트 (13칸)**                \[14\~16번 3칸 휴식\] 클라이맥스 울림 후 루프 준비
  ------------ ------------------------- -------------------------------- -------------------------------------------------------------------------------------------------------------------------------------

🪈 4. 플루트 (Flute) --- \[서브 멜로디 / 숏 홀드\]
-------------------------------------------------

-   **조작 컨셉:** 홀드 노트마다 끝을 살짝 떼어주어(2\~4칸 간격) 바람
    소리가 살랑거리는 유연함 구현

  ------------ -------------------------- ------------------------------- ---------------------------------------------------
  **마디**     **입력 칸 번호**           **노트 종류 및 길이**           **손맛 & 조작 특징**
  **1마디**    **1\~3번**                 **숏 홀드 (3칸)**               \[4번 1칸 / 5마디 진입 전 여유\] E5 바람 소리
  **2마디**    **5\~7번**, **13\~15번**   **숏 홀드 (3칸)** x 2회         \[8\~12번 5칸 / 16번 1칸 휴식\] C5, G5 홀드
  **3마디**    **9\~14번**                **중형 롱노트 (6칸)**           \[15\~16번 2칸 휴식\] D5 서브 멜로디
  **4마디**    7번, **9\~12번**           엇박 단타 + **숏 홀드 (4칸)**   \[13\~16번 4칸 휴식\] 경과음 연결
  **5마디**    **3\~4번**, **7\~8번**     **숏 홀드 (2칸)** x 2회         \[5\~6번 2칸 / 9\~16번 휴식\] 통통 튀는 모험 리듬
  **6마디**    **3\~4번**, **7\~8번**     **숏 홀드 (2칸)** x 2회         \[5\~6번 2칸 / 9\~16번 휴식\] 살랑거리는 홀드
  **7마디**    **5\~7번**, **11\~13번**   **숏 홀드 (3칸)** x 2회         \[8\~10번 3칸 / 14\~16번 3칸 휴식\] E6 고음 홀드
  **8마디**    3번, **7\~10번**           엇박 단타 + **숏 홀드 (4칸)**   \[11\~16번 6칸 휴식\] 8마디 전반부 마무리
  **9마디**    **3\~5번**, **9\~11번**    **숏 홀드 (3칸)** x 2회         \[6\~8번 3칸 / 12\~16번 5칸 휴식\] E6, C6 시원함
  **10마디**   **5\~7번**                 **숏 홀드 (3칸)**               \[8\~16번 9칸 여유\] F6 고음 포인트 홀드
  **11마디**   **3\~4번**, 7, 9번         숏 홀드 (2칸) + 단타 2회        \[5\~6번 2칸 / 10\~16번 휴식\] C6, A5 서브 멜로디
  **12마디**   **3\~5번**, 7, 9번         숏 홀드 (3칸) + 단타 2회        \[6번 1칸 / 10\~16번 휴식\] D6, C6 멜로디
  **13마디**   16번                       **극초단타 (1칸)**              14마디 진입을 위한 살짝 튕김
  **14마디**   **3\~4번**, **7\~8번**     **숏 홀드 (2칸)** x 2회         \[5\~6번 2칸 / 9\~16번 휴식\] C6 하이라이트
  **15마디**   **1\~3번**, **9\~11번**    **숏 홀드 (3칸)** x 2회         \[4\~8번 5칸 / 12\~16번 5칸 휴식\] E6, D6 마무리
  **16마디**   **1\~12번**                **긴 숏 홀드 (12칸)**           \[13\~16번 4칸 휴식\] 1마디로 매끄러운 복귀
  ------------ -------------------------- ------------------------------- ---------------------------------------------------

  ------------ ------------------------------ --------------------------------- ---------------------------------------
  **마디**     **입력 칸 번호**               **노트 종류 및 길이**             **손맛 & 조작 특징**

💡 개발 및 판정 오차범위 (Timing Window) 제언
--------------------------------------------

1.  **단타 판정 (Tap):**

    -   Perfect: [타이밍 윈도우 다이어그램 이미지 - 원본 docx 참고]

    -   Great: [타이밍 윈도우 다이어그램 이미지 - 원본 docx 참고]

    -   Good: [타이밍 윈도우 다이어그램 이미지 - 원본 docx 참고]

2.  **롱노트 해제(Release) 판정:**

    -   롱노트 끝에 2\~4칸의 여유 공간이 반영되어 있으므로, 롱노트 끝
        지점 Release 오차 범위 내에서 손을 떼었을 때 Perfect 판정이
        이루어지도록 처리하면 훨씬 매끄러운 플레이 경험을 제공합니다.

3.  **팀파니 16마디 롤ing (Roll Hold):**

    -   16마디 1번 칸에서 누르기 시작하여 13번 칸까지 유지(Hold) 후
        떼어내면 피날레 카타르시스를 극대화할 수 있습니다.
