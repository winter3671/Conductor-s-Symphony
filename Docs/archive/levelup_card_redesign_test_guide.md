# 레벨업 카드 프레임 아트 + 확대 - 검증 가이드

이 문서는 **Unity MCP가 연결된 별도 Claude Code 세션**에서 이번 작업을 실측 검증할 때 참고하는
절차서입니다. 아직 커밋하지 않은 상태입니다.

검증이 끝나면 이 파일 하단(4절)에 결과를 추가로 append하고, `archive/`로 옮겨주세요.

## 0. 무엇을 고쳤나

레벨업/엘리트 보상 선택 시 뜨는 카드 3장을 텍스트+단색 배경에서 사용자가 나노바나나로 생성한
카드 프레임 아트(`Assets/Resources/Sprites/UI/LevelUpCardFrame.png`, 1024×1536, 2:3 비율,
남색+금색 오케스트라 테마 액자 디자인)로 교체하고, 카드 크기를 220×270 → 380×570로 대폭 확대했습니다
(사용자 요청 - 메이플스토리 보스전 카드 선택 정도의 크기감).

- **버그 발견+수정**: 코드를 읽어보니 `LevelUpUI`의 카드 버튼 3개는 `Ensure UIComponents()`의
  "없으면 생성" 블록이 아니라 **이미 예전에 Unity 에디터에서 직접 만들어져 `Gameplay.unity` 씬에
  저장돼 있었음**(`cardButtons`/`cardTitleTexts`/`cardDescTexts` 필드가 씬에 비어있지 않은 상태로
  직렬화돼 있어 그 "생성" 블록이 항상 스킵되고 있었음). 그런데 `cardIconImages` 필드만은 씬에 빈
  배열(`cardIconImages: []`)로 남아있어서 **악기/패시브 아이콘이 카드에 전혀 표시되지 않는 기존
  버그**가 있었음(사용자가 스크린샷에서 지적한 부분과 일치). `EnsureCardIcons()`를 새로 추가해
  각 카드 버튼 아래에 `IconImage` 자식이 있는지 개별적으로 확인/생성하도록 분리 - 씬에 버튼이
  이미 있든 없든 아이콘만큼은 항상 보장되도록 함.
- **`EnsureCardVisualUpgrade()` (신규)**: `Resources.Load<Sprite>("Sprites/UI/LevelUpCardFrame")`로
  프레임을 로드해 각 카드의 배경 `Image`에 적용(`Image.Type.Simple` - HP/EXP 바·악기 슬롯 프레임
  때와 동일한 이유로 9-slice 대신 사용), 카드 `RectTransform.sizeDelta`를 새 크기(380×570)로
  강제 설정. **이 카드 버튼들이 씬에 박제된 오브젝트라는 걸 발견한 김에, 코드가 항상 최종
  권한을 갖도록 매 `Awake()`마다 명시적으로 덮어쓰게 만들었습니다** - 씬에 남아있던 예전 크기값이
  다시 이기지 않도록.
- **레이아웃을 새 프레임 아트에 맞춤**: `LevelUpCardFrame.png`를 Python으로 픽셀 분석해 3개 구간의
  실제 경계를 실측하고 그 값으로 앵커를 설정함:
  - 제목(`cardTitleTexts`): 헤더 배너 구간(세로 80~97.5%) - 헤더에 장식용 트레블 클레프+월계관
    그래픽이 있어 텍스트와 겹칠 수 있어서, HP/EXP 바 숫자 오버레이 때와 동일하게 `Outline`
    컴포넌트를 추가해 가독성 확보.
  - 아이콘(`cardIconImages`): 중앙 액자 창 구간(가로 25~75%, 세로 46~75%).
  - 설명(`cardDescTexts`): 하단 패널 구간(가로 10~90%, 세로 10~36%).
- **씬/프리팹 직접 편집 없음** - 전부 `LevelUpUI.cs`의 `Awake()`에서 코드로 처리(기존
  `Ensure*Elements()` 패턴 확장).

## 2. 검증 항목

- [ ] 컴파일 에러/경고 0건
- [ ] **텍스처 임포트**: `LevelUpCardFrame.png`가 에러 없이 Sprite(2D and UI)/Single로 임포트되는지
      확인.
- [ ] **육안 확인 (가장 중요)**: 레벨업 발생시켜(예: `PlayerExperience`에 경험치 강제 지급 또는
      `LevelUpUI.ShowLevelUpSelection()` 직접 호출) 카드 3장이 새 프레임 아트로 표시되는지, 크기가
      확실히 커졌는지(220×270 → 380×570) 스크린샷으로 확인.
- [ ] **아이콘 표시 확인 (기존 버그 수정 검증)**: 악기 카드(예: 아직 미보유 악기가 후보로 뜬 경우)에
      해당 악기 아이콘이 중앙 액자 창 안에 정상적으로 표시되는지 확인 - 지금까지는 `cardIconImages`가
      빈 배열이라 아이콘이 전혀 안 보였던 것이 이번에 고쳐진 부분이라 특히 꼼꼼히 확인 필요. 패시브
      카드는 기존과 동일하게 테마 컬러 원형 플레이스홀더(`passiveIconSprite`)가 보이는지 확인.
- [ ] **텍스트 배치/가독성**: 제목(헤더 배너 위)과 설명(하단 패널 위) 텍스트가 프레임의 장식
      그래픽과 겹쳐서 안 읽히는 부분 없이 잘 보이는지 확인. 특히 제목 텍스트가 헤더의 트레블
      클레프/월계관 장식과 겹치는 부분에서 Outline 덕분에 가독성이 확보되는지 확인.
- [ ] **카드 3장 정렬**: 카드가 1장/2장/3장일 때(후보 개수에 따라 동적으로 달라짐) 각각 화면
      중앙에 잘 정렬되는지, 화면 밖으로 잘리지 않는지 확인(카드가 커진 만큼 특히 3장일 때 화면
      가로 폭에 잘 맞는지 - `CardWidth*3 + CardSpacing*2 = 1180px` 확인).
- [ ] **카드 선택 동작 회귀 없음**: 카드를 클릭(또는 숫자키 1/2/3)해서 선택했을 때 기존과 동일하게
      악기 획득/업그레이드 또는 패시브 강화가 정상 적용되고, `Time.timeScale`이 복원되며 카드
      패널이 닫히는지 확인.
- [ ] **일시정지 메뉴와의 상호작용 회귀 없음**: 레벨업 카드가 떠 있는 동안 ESC를 눌러도 일시정지
      메뉴가 열리지 않는지(`LevelUpUI.IsSelectionActive` 가드, 직전 작업에서 이미 확인했지만 카드
      크기/레이아웃이 바뀌었으니 간단히 재확인 권장).

## 4. 검증 결과

(2026-08-10, Unity MCP 세션에서 `Gameplay.unity` Play 모드 실측 검증 + 발견된 버그 수정)

### 4.1 통과한 항목

- [x] **컴파일 에러/경고 0건**.
- [x] **텍스처 임포트**: `Resources.Load<Sprite>("Sprites/UI/LevelUpCardFrame")` 정상 로드
      (`rect=1024x1536`, `border=(0,0,0,0)` - Simple 사용이라 border 불필요).
- [x] **육안 확인**: `LevelUpUI.ShowLevelUpSelection()`을 직접 호출해 카드 3장을 띄우고 스크린샷
      확인 - 새 프레임 아트(남색+금색 액자, 트레블 클레프/월계관 장식)로 정상 표시되고, 카드가
      확실히 커진 것을 확인(220×270 대비 눈에 띄게 확대, 380×570 비율과 일치하는 2:3 세로 카드).
- [x] **아이콘 표시 확인(기존 버그 수정 검증)**: `Drums [Lv.2]` 업그레이드 카드가 뜬 순간을 잡아
      스크린샷 확인 - 드럼 아이콘이 중앙 액자 창 안에 정상적으로 표시됨. **가이드가 지적한 기존
      버그("`cardIconImages`가 빈 배열이라 아이콘이 전혀 안 보임")가 실제로 해결된 것을 확인.** ✅
      패시브 카드는 테마 컬러로 물들인 원형 플레이스홀더가 정상적으로 표시됨(초록/노랑/하늘색/
      분홍 등 카드마다 다른 색).
- [x] **카드 3장 정렬**: `CardWidth*3 + CardSpacing*2 = 1180px`가 캔버스(2560px 폭) 안에 여유
      있게 들어가 화면 밖으로 잘리지 않고 중앙에 정렬됨(스크린샷 확인).
- [x] **카드 선택 동작 회귀 없음**: `Drums [Lv.2]` 카드를 선택 → `InstrumentManager`의 Drums
      레벨이 1→2로 실제 반영, `IsSelectionActive`가 `False`로 전환, `Time.timeScale`이 1로
      복원되는 것을 확인.
- [x] **일시정지 메뉴와의 상호작용 회귀 없음**: 이번 변경은 `LevelUpUI`의 시각적 레이아웃만 건드리고
      `RhythmUI.HandleEscapeInput()`의 가드 로직(`IsSelectionActive` 체크)이나 그 순서는 전혀
      건드리지 않았음(코드 diff 확인). 직전 작업(`pause_menu_test_guide.md`)에서 이미 동일한 가드를
      실제 시뮬레이션 ESC 키 입력으로 검증했으므로, 코드 경로가 안 바뀐 이 항목은 재검증 생략.

### 4.2 [발견+수정] 패시브 카드 타이틀 3줄이 헤더 영역을 넘쳐서 아이콘 프레임과 겹침

`EnsureCardVisualUpgrade()`가 헤더 배너 앵커를 카드 높이의 80~97.5%(≈100px)로 잡아뒀는데,
`ShowLevelUpSelection()`의 패시브 카드 타이틀은 원래 3줄
(`"[Key N]\n이름 뱃지\n<size=11>(테마)</size>"`)이었음. 실측 스크린샷에서 확인한 결과, 세 번째
줄("(테마)")이 헤더 영역 아래로 흘러나와 아이콘 액자의 위쪽 테두리 장식과 겹쳐 매우 작고 읽기
어렵게 보였습니다 - legacy `UI.Text`가 `<size>` 리치 텍스트 태그로 글자 크기는 줄여도 **줄 높이
계산엔 반영하지 않아** 3줄 전부가 기본 `fontSize`(26) 기준 줄 높이로 계산되어 실제로 넘친 것으로
보입니다(악기 카드는 2줄이라 이 문제가 없었음).

- **조치**: 테마 텍스트를 이름/뱃지와 같은 줄로 합쳐 패시브 카드도 악기 카드와 동일하게 2줄로
  줄임(`LevelUpUI.cs`의 패시브 타이틀 조합부).
- **재검증**: 수정 후 스크린샷에서 "Vivace [NEW] (기동성)"처럼 한 줄에 자연스럽게 표시되고, 헤더
  영역 안에 깔끔하게 들어가 아이콘 프레임과 겹치지 않는 것을 확인. ✅

### 4.3 확인하지 않은 항목

- **카드 1장/2장일 때의 정렬**: 현재 게임 진행 상태(초반, 슬롯 1개 + 패시브 8종 대부분 미보유)에서는
  항상 후보가 3개 이상이라 3장 케이스만 실측됨. 코드상 `activeCount`에 따라 `totalWidth`/`startX`를
  동적으로 계산하는 로직 자체는 기존과 동일한 패턴(카드 크기만 상수로 교체)이라 회귀 위험은 낮다고
  판단, 별도로 후보를 인위적으로 줄여 1~2장 케이스를 강제 실측하지는 않았음.
